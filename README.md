# Spotify Song Clustering Analysis

This project focuses on clustering and analyzing Spotify songs from the Rolling Stone dataset using machine learning techniques.

The notebook includes:
- data preprocessing
- exploratory data analysis
- feature scaling
- clustering analysis
- visualization and interpretation of clusters

Concepts covered:
- Unsupervised Learning
- K-Means Clustering
- Data Visualization
- Feature Correlation
- Cluster Interpretation

Libraries used:
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
