# Rolling Stones Spotify Song Clustering

## Overview
This project analyzes Spotify audio features from Rolling Stones songs to identify natural groupings of songs using unsupervised machine learning techniques. The objective is to create song cohorts based on musical characteristics and better understand patterns within the music catalog.

## Methodology
* Data Cleaning and Preparation
* Exploratory Data Analysis (EDA)
* Feature Analysis
* Dimensionality Reduction
* Cluster Identification
* K-Means Clustering
* Cluster Interpretation and Visualization

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Results
Multiple song cohorts were identified based on similarities in audio characteristics. The clustering process revealed distinct musical patterns and provided insights into song composition, popularity, and listening behavior.

## Key Skills Demonstrated
* Unsupervised Learning
* Clustering Analysis
* K-Means Clustering
* Dimensionality Reduction
* Data Visualization
* Feature Analysis

## Conclusion
This project demonstrates how unsupervised machine learning techniques can be applied to music data to create meaningful song clusters and support recommendation-driven applications.
